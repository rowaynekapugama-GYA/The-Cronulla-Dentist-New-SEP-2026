GA4 — THREE FILES THAT MUST GO UP TOGETHER
==========================================

  site.config.ts          holds ga4Id: 'G-XDZHHZLVYL'
  components/Gtm.tsx      the Ga4 component that renders the tag
  app/layout.tsx          calls <Ga4 /> in the page head

Upload ALL THREE in one go, into the repo root so the paths land as
site.config.ts, components/Gtm.tsx and app/layout.tsx.

This is almost certainly why you got the two red Error builds earlier. The
three files reference each other:

  app/layout.tsx  imports Ga4 from  components/Gtm.tsx  which reads  ga4Id
  from  site.config.ts

Upload layout.tsx on its own and the build fails with "Ga4 is not exported
from @/components/Gtm", because the file it is importing from is still the old
version. Same story in reverse. Vercel then keeps serving the previous build,
which is why the site looked unchanged rather than broken.

That is the general rule with this project: when I send you a batch, upload
the whole batch in one commit. Files that changed together need to land
together.

After uploading, watch the deployment go green, then load the site and view
source. Searching for G-XDZHHZLVYL should find it. GA4 Realtime will show you
within about a minute.
