It shows two things:

1. What the live function can actually see for each of the four environment
   variables. It flags a value pasted with a stray space or line break, which
   is invisible in the Vercel screen and is one of the few things that can
   break a key that was working yesterday.

2. The result of one real send through SMTP2GO, with SMTP2GO's own reply
   printed word for word. That is the bit we have never been able to see. The
   forms only ever say "we could not send", which is the same message whether
   the key is wrong, the sender is not verified, or the account is out of
   credits.

The API key is NOT printed. Only its length and first and last few characters,
which is enough to confirm it matches without exposing it on a public URL.
