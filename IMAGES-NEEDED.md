# Images needed — The Cronulla Dentists

The three assets from the live EOI page are **in place** (§1). Everything else still ships as a clearly labelled placeholder in `public/images/` — replace each file **keeping the same filename** and redeploy.

> **Replacing a photo now busts the cache automatically (added 10 Sep 2026).** Every image URL carries a short hash of the file's own contents, e.g. `/images/services/x.jpg?v=1a2b3c4d`. This matters because Vercel's image optimizer caches each optimized image against its SOURCE URL, not its bytes — so before this change, dropping a new photo in at the same filename left the URL identical and the CDN kept serving the old picture no matter how many times the site was redeployed. The hashes live in `lib/image-manifest.json`, regenerated by `scripts/gen-image-manifest.mjs` on every build via the `prebuild` / `prebuild:static` npm hooks, so it cannot drift from what is on disk. Nothing to do by hand: replace the file, redeploy, and the new photo appears. (The offline preview strips `?v=` back off, because a `file://` URL treats a query string as part of the filename.) All photos: JPG, sRGB, quality ~80, longest edge as noted. Photos are shown in rounded 24px panels with a navy gradient caption at the bottom on some slots — keep key subjects away from the bottom 25%.

("Payment Solutions", "first choice", "Fast claims… on the spot"), so a tagline

on the spot" directly above where "Claim on the spot" would have sat. The
tagline is kept in each logo's alt text, and the wordmark fallback still shows it.

To replace a logo, drop a new file in `public/images/providers/` under the same
base name — `.svg`, `.png`, `.webp` and `.jpg` are tried in that order, SVG
preferred. Remove all three and the cards fall back to styled wordmarks with
taglines; the layout stays correct either way. The lookup is `lib/providers.ts`.

**Check the nib program name before launch.** The supplied logo is **nib first
choice**, which is nib's specific dental provider network. The site's copy calls
it "preferred provider" — fair as a description, but the logo names the actual
program, so the practice needs to be in *that* program for the mark to be used.
Same for HICAPS "claim on the spot", which needs a terminal in the practice.

**Where to get them.** From DentiCare, nib and HICAPS themselves — each runs a
partner or media kit with approved logo files and usage rules for practices that
hold the relevant arrangement. These are registered trade marks: taking the
files off another dental practice's website copies their hosted asset and skips
the permission that makes the use legitimate. Two of the three taglines are also
factual claims — "nib preferred provider" and HICAPS "claim on the spot" — so
they should only go live once those arrangements are actually in place.

## 9. A note on the Teeth Whitening image

`services/teeth-whitening-cronulla.jpg` is a retouched studio close-up of an
idealised white smile. It was supplied deliberately and signed off for use.

Worth revisiting when practice photography is available, for three reasons:

- **It pulls against the copy.** The page opens by naming teeth whitening as
  "the one most surrounded by inflated claims" and says "we would rather set
  expectations properly at the start." An idealised result image is the claim
  the words are disowning.
- **Advertising risk.** It is not a before/after, so it does not breach that
  rule outright. But advertising a regulated health service must not create an
  unreasonable expectation of beneficial treatment, and an idealised outcome
  image on the whitening page is the clearest example of that on the site.
  Compliance sign-off sits with the practice.
- **It breaks the photo set.** Every other service photo is an environmental
  in-practice shot with people and a clinician. A close-crop of a mouth on
  white reads differently, and the white background gives the rounded photo
  card almost no edge against the white page section — the hard-left crop used
  here is what keeps the card readable.

Safer replacements that show the treatment rather than promising the result:
whitening trays in hand, the in-chair light or setup, a shade guide held beside
a patient, or a normal consultation shot.

To swap it: replace the file (the page and the menu card both follow it).
